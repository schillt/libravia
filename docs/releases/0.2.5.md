# LibraVia 0.2.5 alpha

Source marketing version **0.2.5**, repository build **56**. The immutable `v0.2.5` tag and GitHub release identify the exact candidate. TestFlight archive, upload, Apple processing and tester availability are separate checkpoints; this source prerelease makes no availability claim.

This prerelease brings a native reader and library polish pass together with early local reading tools and offline-library features. It is an alpha for testing: the remaining 0.2 acceptance checks and the expanded 0.3 reliability and sync gates are still open.

- Refined the reader controls, EPUB page turns, opening transition, Mac inspector, and resizing behavior. The library and book details offer improved layouts and controls.
- Use EPUB text selection to highlight passages or add notes, and find reading tools in the reader. The Mac reader also offers a persistent color highlighter. Local bookmarks, other format-specific notes and highlights, and reading-data export are available for further testing.
- Save supported books to the device, import DRM-free EPUB, PDF and CBZ files, or choose a book folder for a standalone library. Download management and storage controls are included for testing.
- An option to keep the screen awake while reading is available on iPhone and iPad.

**Reading data and sync:** Highlights, notes, bookmarks, and imported books in this alpha are local. Existing Jellyfin progress behavior is separate; annotation and imported-book iCloud synchronization and restore are not connected. Signing out of Jellyfin warns before deleting that account's local reading data, including unsynced annotations; a separately selected book folder remains user-owned. Local app data can also be lost when the app is removed. Keep a separate backup of anything important.

Offline restart, interruptions, low-storage and corruption handling, account isolation, other-format annotations, export, and migration still need the 0.3 acceptance pass. The latest phone build has not been installed or accepted on the physical device. Mac visual feedback is positive but does not constitute the complete cross-platform release gate.

Gate [#28](https://github.com/schillt/libravia/issues/28) and the [0.3 gate #29](https://github.com/schillt/libravia/issues/29) remain open. See [roadmap](../ROADMAP.md), [handoff](../HANDOFF.md), [validation](../../VALIDATION.md), and [TestFlight setup](../../TESTFLIGHT.md).
