# LibraVia 0.2.0

Alpha source release, authorized 2026-10-08. Marketing version 0.2.0; build 54. No binary distribution is part of this release.

## Shipped scope

The native reading milestone adds continuous EPUB chapter scrolling, rendered-screen/spread counting after typography or viewport changes, exact scrub destinations, publication chapter names and visible chapter breaks. Edge-width preferences support previous/next taps and center control toggles; vertical reading retains scrolling and omits page arrows. Card previews show genuine adjacent content, rapid turns interrupt decoration, and iPhone/iPad offer native page curl. Chapter-boundary haptics and page-owned quiet reading information accompany mobile control improvements.

Mac books open in a separate resizable window. Native menus, text-size shortcuts and trackpad-driven EPUB turns complement a stable floating glass inspector for contents, appearance and search. Inline sliders update live; layout operations coalesce and preserve locations through an interruptible stretch/compact transition. Reader paper color also sets browsing surfaces. Catalog covers/title rows are consistent and opening dots fill left to right. PDF layout preserves the visible destination; comic decoding is cancellable and zoom/pan are separated from page input.

## Evidence and limitations

The feature candidate passed 70 core tests, reader/frame JavaScript checks, three performance-report tests, trackpad reducer checks, a Mac build and a native WebKit pagination/reflow stress probe. Static security scan `95fd6ec3-b117-4aca-936b-eb2400a336a1` reviewed all31 changed files with no reportable vulnerabilities, exclusions or deferred candidates. Source integration preserves the reviewed runtime tree. The metadata/documentation delta receives its own pre-push review and version/build validation; exact final outcomes are recorded in the release PR and GitHub release.

Physical iPad, accessibility, final iPhone curl/search/haptics, sustained real-book Mac slider/inspector stress and trackpad feel remain open. Fixture success does not prove the reported real-book quitting/lockup resolved. Phone installation evidence belongs to `8ce1dc26f714c2eebefeb0bc539b5bb42694a4f6`, not the final release. Performance baselines identify their own older candidate and are not release benchmarks. Adversarial WebKit/runtime tests, live-server interoperability, signed distribution and TestFlight availability are not established by this release.

Gate [#28](https://github.com/schillt/libravia/issues/28) remains open; source-release designation does not waive unrecorded acceptance. beta/preview/main remain unchanged. Cached books remain disposable, not permanent offline saves. Current support is Jellyfin and DRM-free EPUB/PDF/CBZ; additional providers, local import, annotations and durable downloads remain roadmap work.
