# LibraVia 0.3.0 — private recovery

Owner-authorized GitHub source release, version **0.3.0/build 59**. The immutable `v0.3.0` tag identifies the published source. Version 0.2.5 was promoted unchanged to main first through PRs #67, #68 and #69; final main promotion commit `e8f0d2a6b117a9741b5fdd5647a35e2c045fbeb2` exactly matches the existing `v0.2.5` tree.

## Delivered

- Opt-in private CloudKit synchronization and recovery for managed standalone EPUB, PDF and CBZ original files, metadata, precise positions, bookmarks, highlights and notes.
- Separate private recovery for Jellyfin-linked reading data that the server does not support; Jellyfin book files remain on the server. Local reading works without iCloud.
- Atomic local journals/outboxes, conditional uploads, retained conflict alternatives, deletion tombstones, interrupted-operation retries and reviewed account switches. Source/account/book/edition identity remains distinct.
- Durable offline saves, import and selected-folder ownership safeguards; validated assets and failure/retry paths preserve original source files and reading data.
- EPUB continuous-scroll visibility restoration and status-bar scroll-to-top protection. Saved positions are edition-verified before reader construction; earlier places are backed up before a reviewed replacement. CBZ annotations wait for readable page content.
- Editable, edition-aware bookmarks and searchable reading tools. Markdown/JSON exports include book/author/format/source context without automatically exposing connection/account fields.
