# Security reports

Do not publish credentials, private server addresses, personal library data, reproduction books without permission, or raw request/response logs in an issue.

Use the repository's private vulnerability reporting feature if enabled. If it is unavailable, request a private reporting channel from the maintainer without posting sensitive details. There is no guaranteed response time or security certification for this MVP.

A useful report describes the affected version, platform, preconditions, expected and observed behavior, and a reproduction using a synthetic account and original/public-domain fixture. Mask identifiers and tokens. Do not test against servers or accounts you do not control.

Privacy implementation notes and unresolved distribution checks are documented in PRIVACY.md and VALIDATION.md.
